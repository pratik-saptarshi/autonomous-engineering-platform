## Rollback runbook (executable; use only on failure)

1. **Revert a bad forward merge on a working branch** (non-destructive, preferred):

   ```sh
   git clone "https://github.com/pratik-saptarshi/<tree>.git" rollback-<tree>
   cd rollback-<tree>
   git revert --no-edit <merge-commit-sha>       # the --no-ff merge made by Task 4/5
   git push origin <working-branch>
   ```

2. **Restore a mirror from the bundle** (destructive; requires separate explicit owner authorization for the force-push, per `AGENTS.md` — never do this automatically):

   ```sh
   git clone --mirror <bundle-path> restore-<tree>.git
   git -C restore-<tree>.git push --force "https://github.com/pratik-saptarshi/<tree>.git" \
     backup/pre-sync-<tree>-mirror:refs/heads/<mirror-branch>
   ```

3. Verify restoration with `gh api repos/<fork>/compare/<pre-sync-sha>...<branch>` → `identical`, and confirm all recorded fork-only SHAs are present.

The pre-sync SHAs above are also held by the mirror-clone tags and inside the bundles, so a moved ref cannot lose them to GC.
