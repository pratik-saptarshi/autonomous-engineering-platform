### Task 2: Author scripts/boot-gate.sh

**Files:**
- Create: `scripts/boot-gate.sh` (executable, `set -euo pipefail`)

**Interfaces:**
- Consumes: nothing (new file)
- Produces: `scripts/boot-gate.sh` for Task 4's commit; contract: exit 0 iff all gates pass, non-zero otherwise; `--self-test` runs the stub-based tests and exits 0 iff they all behave as expected.

- [ ] **Step 1: Write `scripts/boot-gate.sh`**

Checks, in order, each printing `BOOT-GATE: <name> ok` or `BOOT-GATE: <name> FAIL: <reason>` (FAIL → exit 1 immediately):
1. `binaries` — `for b in neurostrata-mcp bd ocr gh; do command -v "$b" >/dev/null || fail; done`
2. `daemon` — `out=$(neurostrata-mcp status 2>&1)` must contain `answering`, else FAIL (handles daemon-down without crashing on `set -e`: capture first, test second)
3. `guards` — `out=$(neurostrata-mcp list guard 2>&1)`; parse the `Found N memories` line, require N ≥ 3; AND `grep -q "Destructive GitHub actions"` on the output, else FAIL
4. `gh-auth` — `gh auth status >/dev/null 2>&1`, else FAIL

`--self-test` mode: creates a temp stub dir with fake `neurostrata-mcp` (cases: status without "answering"; `list guard` printing "Found 0 memories"; `list guard` without the destructive-actions rule) and fake `gh` (exit 1), then asserts the gate exits non-zero for each case and exits 0 for the real environment. Each assertion prints `SELF-TEST: <case> ok`.

- [ ] **Step 2: Positive run on this VM**

Run: `bash -n scripts/boot-gate.sh && chmod +x scripts/boot-gate.sh && ./scripts/boot-gate.sh`
Expected: exit 0; four `BOOT-GATE: <name> ok` lines.

- [ ] **Step 3: Negative self-test**

Run: `./scripts/boot-gate.sh --self-test`
Expected: exit 0; all `SELF-TEST: <case> ok` lines present (daemon-down, zero-guards, missing-destructive-rule, gh-auth-fail, plus the real-environment positive).
