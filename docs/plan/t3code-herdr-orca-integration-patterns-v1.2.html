This reference artifact formalizes the integration topology connecting the developer desktop environment to the Autonomous Engineering Platform (AEP) substrate. It establishes the technical contracts, event pipelines, and credential boundaries between T3 Code (AI-assisted harness and thread orchestrator), Herdr (GPUI agent multiplexer and terminal harness), and Orca (agent lifecycle, telemetry, and supervision daemon).

2. Interaction Sequence & Agent Lifecycle State Machine

3. Detailed Specifications of the Four Integration Patterns

Pattern A: Workspace Reflection (Virtiofs) T3 Code provisions Git worktrees bound to isolated thread IDs. Virtiofs reflects all file modifications between container lanes and the host instantly. Herdr's watchFolder receives kernel events without polling, instantly refreshing syntax-highlighted diffs in open multiplexer panes.
Pattern B: Agent Lifecycle FSM (Orca) OpenCode, Claude Code, and Pi harness execution states flow into Orca's daemon over local domain sockets. State transitions (SessionStart → SessionBusy → SessionWaiting → SessionIdle) drive Herdr's attention routing and T3 Code's turn completions.
Pattern C: Zero-Token-Leak Socket Relays Execution lanes are locked down with --network none or measured EgressProbe boundaries. GitHub PATs and LLM provider secrets stay strictly on the host. Sockets mounted at /run/aep/lanes/<laneId>/ proxy memory queries, GitHub calls (capped at 3,500 req/h), and model harness interactions.
Pattern D: Cryptographic Settlement Verification executes via the Go static binary aep verify, hashing every stdout/stderr byte. RFC 8785 canonical receipts signed with Ed25519 are mandatory for bd close <issueId> ledger settlement, continuous memory inscription, and automatic GitHub PR linking.

4.2 Interaction Lifecycle (Sequence Diagram)

sequenceDiagram
  autonumber
  actor User as Developer / Operator
  participant T3 as T3 Code
  participant Herdr as Herdr Multiplexer
  participant Orca as Orca Daemon
  participant AEP as AEP Supervisor & Lanes
  participant Substrate as Substrate (Beads & Memory)

  User->>T3: Launch engineering task (Thread / Goal)
  T3->>T3: Allocate Git worktree (workspaceStrategy: "worktree")
  T3->>AEP: Dispatch task to Lane (Tier 1 Ralph or Tier 2 ESF)
  AEP->>Orca: Agent session started (SessionStart)
  Orca->>Herdr: Post status: Lane Busy (SessionBusy)
  Herdr->>Herdr: Render active spinner in agent pane

  rect rgb(240, 248, 255)
    note over AEP,Substrate: Execution inside --network none sandbox
    AEP->>AEP: Run agent loop & execute code changes
    AEP->>Substrate: Relayed tool/memory query via supervisor socket
    AEP->>T3: File writes reflected via virtiofs
    Herdr->>Herdr: watchFolder detects changes (instant UI reflection)
  end

  alt Agent requires operator input / approval
    AEP->>Orca: Form / permission requested
    Orca->>Orca: Transition FSM to SessionWaiting
    Orca->>Herdr: Broadcast waiting state over IPC socket
    Herdr->>User: Fire notification toast & focus agent pane
    User->>Herdr: Review diff & submit approval
    Herdr->>AEP: Pass input back via exec.sock
  end

  rect rgb(245, 243, 255)
    note over AEP,Substrate: Deterministic Verification & Settlement
    AEP->>AEP: Run aep verify (full StdoutSha / StderrSha)
    AEP->>AEP: Sign CommandReceipt with Ed25519
    AEP->>Substrate: Settle issue (bd close <id>) & inscribe NeuroStrata
  end

  AEP->>Orca: Session completed (SessionIdle)
  Orca->>Herdr: Update terminal badge to green checkmark
  Orca->>T3: Report thread turn completion
  T3->>T3: Call link_pull_request with verified branch PR
  T3->>User: Display completed task summary & rendered deliverables
