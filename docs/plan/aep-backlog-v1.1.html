1. Adversarial Panel Findings & Architecture Calibrations

Adversarial Audit Summary (Planning-Wringer, Paperthin & Uncle Bob): The adversarial review panel audited the v1.1 backlog against the live repository (cmd/aep, internal/, tools/ghg, reference/esf) and surfaced 4 fatal design risks and interface coupling flaws that have been remediated in this refined plan:
Adversarial Finding & Challenge Ground-Truth Reality & Risk Applied Backlog Remediation
1. ESF Multi-Backend Gap
(Planning-Wringer)		 reference/esf/go.mod:7 hardcodes CubeSandbox/sdk/go v0.7.3. Zero native code exists for libkrun or gvisor. Modifying reference/esf is forbidden. Descope in-tree ESF modifications: Cube/KVM is the verified factory path. libkrun and gvisor are designed as out-of-tree runner adapters behind the factory.BackendAdapter seam. Unsupported hosts cleanly quarantine.
2. VirtioFS / Worktree Deadlock
(Paperthin Devil's Advocate)		 Running 8–10 parallel container lanes mounted to host Git worktrees via VirtioFS on macOS Colima causes severe inode lock contention and .git/index.lock race collisions. Strict Worktree Isolation: Each lane operates in an independent branch worktree with isolated index paths (GIT_INDEX_FILE=/tmp/index) and dedicated build cache volumes (tmpfs), preventing lock contention.
3. Interface Coupling & SRP Violations
(Uncle Bob Clean Architecture)		 lane.Manager and factory.Client were god interfaces bundling process execution, worktree allocation, filesystem fencing, and cryptographic auditing into monolithic structs. Interface Segregation (ISP): Segregated into WorktreeAllocator, ContainerRuntime, FenceCoordinator, BackendProbe, and EgressAuditor. Pure domain policies separated from disk I/O.
4. Closed-Egress Dependency Catch-22
(Paperthin Adversary)		 Enforcing allow_internet=false inside Tier-2 sandboxes prevents tasks from downloading missing compiler packages or external test dependencies during builds. Pre-Baked Runtime Images & Read-Only Caches: System dependencies and language modules are pre-seeded in the base lane image or mounted via read-only host volume caches. Egress remains strictly closed.
5. Fatal 8 GB RAM Physical Check Bug
(Planning-Wringer)		 Backlog AC-07.1.1.3 checked for < 8 GB available RAM, which fails on physical 8 GB machines (Intel N100) because OS overhead leaves ~6–7 GB available. Check Physical Memory: AC-07.1.1.3 updated to evaluate total installed physical RAM (Total >= 7.5 GiB) rather than instantaneous available memory.
6. Redundant Receipt Package
(Planning-Wringer)		 Backlog invented a redundant internal/receipt package duplicating existing runner.CommandReceipt in internal/verifier/runner/runner.go:21-30. SSOT Consolidation: Merged receipt generation into existing internal/verifier/runner primitives, eliminating split-brain receipt structures.

5. Detailed Backlog Specifications (ISP / SRP Refactored)

CAP-01 Tier-1 Ralph Container Isolation REQ-01.1 · Package: internal/lane

Executes inner-loop tasks in ephemeral OCI containers with isolated network namespaces, tmpfs /tmp, virtiofs git worktrees, and IPC relays.

Segregated Clean Interfaces (ISP):
type WorktreeAllocator interface {
  Allocate(ctx context.Context, issueID string) (worktreePath string, err error)
  Free(ctx context.Context, worktreePath string) error
}
type ContainerRuntime interface {
  Start(ctx context.Context, spec ContainerSpec) (containerID string, err error)
  Wait(ctx context.Context, containerID string) (exitCode int, err error)
  Stop(ctx context.Context, containerID string) error
}
type LaneManager struct {
  allocator WorktreeAllocator
  runtime ContainerRuntime
  fences FenceStore
}
Behavioral Acceptance Criteria (TDD):
  • AC-01.1 (Confinement): GIVEN a spawned container, WHEN executing any outbound socket call, THEN the kernel returns ENETUNREACH or EPERM immediately.
  • AC-01.2 (Lock Free): GIVEN 4 concurrent lanes, WHEN git commits execute simultaneously, THEN isolated index files prevent .git/index.lock collisions.
  • AC-01.3 (Reap Safety): GIVEN a launcher process killed with SIGKILL while the container runs, WHEN aep lane reap runs, THEN it marks the lane active and refuses to delete state until the container stops.
CAP-02 Tier-2 Local-First Sandbox Factory REQ-01.2 · Package: internal/factory

Executes untrusted dependencies, multi-repo changes, and CVE remediation in hardware microVMs with measured egress.

Segregated Clean Interfaces (ISP):
type BackendProbe interface {
  Probe(ctx context.Context) (SandboxBackend, error)
}
type PipelineRunner interface {
  Submit(ctx context.Context, req RunRequest) (handle RunHandle, err error)
  Status(ctx context.Context, handle RunHandle) (RunStatus, error)
}
type EgressAuditor interface {
  VerifyProbeDigest(ctx context.Context, evidencePath string) (bool, error)
}
Behavioral Acceptance Criteria (TDD):
  • AC-02.1 (Hardening Guard): GIVEN factory.toml with hardening.acknowledge_open_egress = true, WHEN submitted, THEN runner rejects with exit 4.
  • AC-02.2 (Backend Resolution): GIVEN Linux with /dev/kvm, THEN selects cube-kvm; GIVEN host lacking hardware virtualization, THEN selects gvisor adapter or safely quarantines.
  • AC-02.3 (Dependency Pre-Baking): GIVEN closed egress (allow_internet=false), WHEN build scripts run, THEN required dependencies resolve from pre-seeded image layers or read-only volume mounts without external network access.
CAP-07 Multi-Hardware Profile Registry & Admission REQ-04.1 · Package: internal/profile & internal/admission

Enforces hardware budget scaling from 2 vCPU / 8 GB (Intel N100) up to 12 vCPU / 48 GB (Apple M3 Max) with dual-constraint admission.

Pure Domain Logic Decoupled from I/O:
type Usage struct {
  ActiveLanes int
  AllocatedRAM int
}
// Pure calculation without disk locking or syscalls:
func CalculateAdmission(u Usage, p Profile, req ReservationReq) (*Reservation, error)
Behavioral Acceptance Criteria (TDD):
  • AC-07.1 (Physical Memory Floor): GIVEN a host with TotalRAM >= 7.5 GiB (physical 8 GB), WHEN aep profile detect runs, THEN it successfully assigns preset nano-8g regardless of ephemeral available RAM.
  • AC-07.2 (Dual-Constraint Concurrency): GIVEN an active memory budget of 4.0 GB, WHEN two 2.0 GB lanes are active, THEN a 3rd lane request receives ErrNoCapacity even if the lane count ceiling is not reached.
