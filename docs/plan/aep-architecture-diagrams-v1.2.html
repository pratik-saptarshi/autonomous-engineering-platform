This reference artifact captures the complete architectural topology of the Autonomous Engineering Platform (AEP) as the Agentic-Container OS. It formalizes two complementary operational tiers—fast inner-loop container lanes (Tier 1: Ralph) and sandboxed outer-factory pipelines (Tier 2: ESF)—governed by a shared substrate, fail-closed preflight gates, and cryptographic auditability.

1. High-Level Architecture Overview (AEP as the Agentic-Container OS)

End-to-end topology showing physical host hardware profiles, containment runtimes, control plane governance, substrate core services, dual-lane execution fabric, and verifiable settlement.

Dual-Constraint Admission Simultaneously enforces hard concurrent lane count ceilings and cumulative RAM budgets parameterized by hardware profile. Protects host memory floor with underflow-safe arithmetic.
Zero-Egress Isolation Lanes execute with --network none. All I/O occurs via host-side socket relays (memory.sock, ghg.sock, git.sock, exec.sock). Provider keys and PAT tokens never enter containers.
Local-First Sandbox Hierarchy Tier 2 prioritizes local execution: (1) Linux KVM, (2) macOS libkrun (vz), (3) user-space gVisor (systrap). Remote clusters are strictly an emergency last resort; otherwise tasks safely quarantine.
Cryptographic Settlement Command receipts bind full-stream stdout/stderr SHA-256 hashes and egress proofs signed with Ed25519. Required for Beads ledger closure and NeuroStrata memory inscription.

Detailed architectural decomposition comparing Tier 1 (Ralph Inner Loop) and Tier 2 (ESF Outer Factory), mapping the 7 vertical operational slices of the sandboxed factory.

ESF Vertical Slice Invariants: Every ESF pipeline executes through all 7 vertical slices in order. An issue cannot settle (bd close) without passing in-VM egress proof verification (Slice 4), full-stream test logging (Slice 5), disposable sandbox re-verification meeting the original IsolationClass (Slice 6), and Ed25519 signature binding (Slice 7).
