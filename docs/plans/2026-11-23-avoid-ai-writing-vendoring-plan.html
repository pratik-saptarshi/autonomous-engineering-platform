Date: 2026-11-23 Decision: Pratik, 2026-11-23 — adopt avoid-ai-writing scoped detect-only Evaluation of record: 2026-11-23 avoid-ai-writing vs humanizers (verdict: adopt-scoped-alongside)

Scope law

  • humanizer stays the default prose pass; ste80-humanizer stays the STE tool. avoid-ai-writing is adopted only as deterministic detect/audit tooling plus (later, separately proposed) a CI prose gate.
  • The skill's rewrite capability is disabled by a day-one fork amendment, so no two skills ever claim the same request.
  • Evidence-bearing artifacts (receipts, verification reports, decision records, NeuroStrata inscriptions) are out of scope for every prose skill, this one included.

Stage 1 — the mirror

  • Repo pratik-saptarshi/avoid-ai-writing (fork of conorbronsdon/avoid-ai-writing, MIT, imported with full upstream history at v3.39.0, commit cd5573a).
  • Create develop from main; set develop as default branch. main stays the pristine upstream mirror — no fork commits on it.
  • Upstream attribution (badges, homepage, npm metadata, LICENSE, NOTICE) stays intact. Defects in the external code are filed on the origin repo only, at the owner's call (venue rule).

Stage 2 — day-one fork amendment (mirror develop)

  • Frontmatter description narrowed to the detect/audit intent; rewrite/edit trigger phrases removed.
  • A "Local scope" section in SKILL.md disables the rewrite and edit modes (detect is the only enabled mode and the default), carries over the evidence-bearing-artifact exclusion, and routes rewrite requests to humanizer and STE requests to ste80-humanizer. Modes/Invocation annotated to match.
  • Fork marking per the fleet convention: fork_of: "conorbronsdon/avoid-ai-writing" + fork_version in SKILL.md frontmatter (upstream version: 3.39.0 untouched), plus FORK.md with origin pin, fork version, and a dated change log. Amendment 1 set fork_version 1; Amendment 2 (same day, closing a rewrite trigger the independent review found in the generated Cursor rule's generator-hard-coded description) set fork_version 2.
  • Derived artifacts regenerated with the repo's own sync scripts (sync-plugin-skill.sh, sync-cursor-rules.sh) so no generated copy drifts from the amended SKILL.md.
  • Verification: frontmatter parses; npm test (detector, validator, gate, eval suites) passes; detector and gate CLI run against a sample; diff vs main shows only amendment files.
