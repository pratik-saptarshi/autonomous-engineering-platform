# OpenShell Patterns — Phase 0 gate evidence

Evidence for the four Phase 0 gates of the OpenShell-patterns adoption plan
(plan + panel verdict live in the AEP vendored repo maintenance lane files;
the results report is `docs/plans/2026-11-13-openshell-patterns-phase0-results.html`).

- `g-p2/` — power-differ historical replay (prototype differ, universe, per-PR deltas, seeds)
- `g-p7/` — ESF credential post-run replay probe + run inventory
- `g-p6/` — autonomous launch-path census (boot-gate.sh invocation coverage)
- `g-p11/` — authority-index time-to-answer test + generation feasibility

All artefacts here are Phase 0 evidence: throwaway prototypes and censuses,
not production tooling. Gate verdicts follow the plan's pre-registered
pass/kill criteria exactly.
