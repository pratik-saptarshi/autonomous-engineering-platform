# Security Policy

## Reporting a vulnerability

If you find a security issue in this repository, please report it
privately through GitHub's private vulnerability reporting for this
repository (Security tab, then Report a vulnerability). Please do not
open a public issue for a suspected vulnerability.

Include as much detail as you can: what you found, where it is, and
how it can be reproduced. Reports are taken seriously and will be
acknowledged as soon as possible.

## Scope

This repository is a reference architecture and skill library: skills,
reference snapshots, scripts, and documentation. There are no deployed
services, user accounts, or production data in scope here, but secrets
in the tree, supply-chain issues in the vendored snapshots, and
unsafe script behaviour are all in scope for a report.

## What happens next

Confirmed issues are fixed in a pull request like any other change in
this repository, and the fix is credited in the pull request unless
the reporter asks not to be named.
